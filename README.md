# Run & Boom

Browser-Version von **Run & Boom**, dem Spiel von Team 04 aus Programmieren 2 (3. Semester BA WI).
Original in Python/Pygame: [itsMares/finale_version_prog_run_and_boom_team04](https://github.com/itsMares/finale_version_prog_run_and_boom_team04).

- **Auf einem Gerät:** zwei Spieler an einer Tastatur oder zusammen an einem iPad.
- **Online:** Ein Spieler erstellt einen Raum und schickt den Code oder Einladungslink, der andere tritt bei.
- **iPhone/iPad:** Touch-Tasten erscheinen auf der Seite deiner Figur (Runner links, Kanone rechts). Gerät quer halten.

Läuft komplett im Browser (`index.html` + `assets/`). Die Online-Verbindung geht direkt zwischen den Geräten (WebRTC über PeerJS).
